# app.c 业务状态机说明

上电欢迎页以无符号毫秒差计时，约 2 秒后切到待机页。短按 KEY1 可提前进入主页。开门返回待机页。

DHT11 环境温度达到 30 ℃ 或读数无效时，禁止启动。运行或暂停期间发生上述情况，清空本轮倒计时、发出开门命令并进入 `APP_STOPPED`，保留停机原因。短按 KEY1 进入新一轮，温度正常且重新设置时间后才能启动。低压联调与加热 APP 运行时都可长按 KEY2 手动停机。

## 范围与所有权

`ControlTask` 独占调用本文件；其他任务通过快照队列获取 `AppSnapshot`，不直接读写业务状态。业务层不调用 LCD 或延时，不依赖动画是否完成。

保留欢迎、主页、时间、档位、运行、暂停、完成七个页面。上电软件门开、PC13 LED 亮；没有超时自动进入菜单，只有短按 KEY1 关门并熄灯进入主页。

## 操作

| 操作 | 行为 |
| --- | --- |
| KEY1 短按 | 切换软件门状态；运行开门转暂停；设置开门回欢迎；完成后关门进主页 |
| KEY1 长按 | 门关且时间非零时启动；暂停关门后恢复；开门或零秒显示提示 |
| 主页 KEY2 短按 | 进入时间页，本次不加时间 |
| 时间页 KEY2 短按／长按 | 加 20 秒（超过 200 回零）／进入功率页 |
| 功率页 KEY2 短按／长按 | Low → Medium → High 循环／返回时间页 |
| 运行或暂停时 KEY2 | 保持本轮参数，提示暂停或恢复方法 |
| 倒计时归零 | 软件开门亮灯，时间归零、档位恢复 Medium，进入完成页 |

两键同次送达时 KEY1 优先。提示用枚举传递，快照不包含跨任务可变指针。倒计时使用无符号毫秒差，暂停保存毫秒，显示秒数向上取整。`total_ms` 为当前轮次初始时间，供 UI 计算进度，恢复时不重置。

LED 由业务层直接输出；门舵机、转盘和蜂鸣器由 `ControlTask` 比较状态转换后调用执行机构层或发送提示命令。本文件的状态机及按键操作不因接入双舵机而改变。

常规版 `Heating` 表示倒计时和转盘演示运行，PA2 保持关闭。LCD 显示 DHT11 的环境温度。

低压 LED 联调版另外记录 PB10 实际门反馈。KEY1 软件门命令仍控制门舵机和主页入口，KEY2 可在物理门尚未闭合时设置时间和档位。启动或恢复需要软件门命令及 PB10 都确认关闭。物理开门只暂停并保留剩余时间和当前门命令。门开关重新闭合后须重新长按 KEY1，若曾用 KEY1 发出开门命令则先短按发出关门命令。PC13 照明由物理门反馈更新。
