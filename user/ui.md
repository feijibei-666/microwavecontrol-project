# ui.c 分层界面与切换动画

欢迎页约 2 秒后进入 `STANDBY`。主页显示设定秒数和档位，完成页显示本轮运行时间及当前环境温度。停机页显示 `HEATING STOPPED`，并注明过温、温度无效或手动测试。

独立升级构建通过 `FIRMWARE_VERSION` 在欢迎和待机页显示版本，方便核对串口升级后实际启动的镜像。

加热 APP 顶栏显示 `HEAT OUTPUT ON/OFF` 和 PB10 反馈。ON/OFF 为 PA2 继电器命令，调功窗口内关闭输出时倒计时继续。运行中长按 KEY2 可手动停机，停机页显示 `MANUAL STOP`。

## 设计与内存

面向 128×160 ST7735 屏幕，采用深色背景、青蓝强调色、圆角卡片、5×7 小字和七段大数字。绿色表示运行或完成，琥珀色表示暂停与操作提示。

显示任务独占本模块和 LCD。界面使用静态 128×8 RGB565 条带缓冲，仅占 2048 字节；不分配 40960 字节整屏缓冲，不使用动态内存。每次重建一小块场景后，通过同步 `LCD_Blit()` 发送；该函数返回前必须结束 DMA 并消费完缓冲。

界面直接消费 `AppSnapshot` 值副本，不访问控制任务内部变量，也不修改门、LED 和倒计时状态。

空载诊断构建显示独立的 `RELAY TEST / NO LOAD` 页。`PA2 COMMAND ON/OFF` 来自控制任务快照，表示软件驱动命令。命令变化时只刷新状态所在条带。

`PTC_BENCH_TEST=1` 使用 `PTC TEST / 5V / 10 SEC` 标识。完成或取消后显示 `TEST COMPLETE` 和 `RESET TO RETEST`，重新武装需要复位。

LED 倒计时联调构建在所有页面顶栏显示 `LED TEST / PA2 ON` 或 `LED TEST / PA2 OFF`，下一行显示 `PB10 CLOSED` 或 `PB10 OPEN`。运行页标题为 `RUNNING`。PA2 状态文字来自输出层下发的命令，不能测量触点是否导通。命令变化时刷新对应条带，门反馈变化时更新门状态和操作提示。

## 页面

| 页面 | 重点信息 |
| --- | --- |
| 欢迎 | 项目标题、微波炉线条图、开门状态、KEY1 进入提示；不显示时间及档位 |
| 主页 | Ready 卡片、关门状态和设置/启动入口 |
| 时间 | 大时间数字、设置范围进度线、增加与切换提示 |
| 档位 | 当前档位、Low/Med/High 三段选择按钮 |
| 运行 | 剩余秒数、当前档位、烹饪进度条及暂停入口 |
| 暂停 | 剩余秒数、门状态，以及关门或恢复的下一步提示 |
| 完成 | 完成勾选图标及下一轮入口 |

顶部用当前页标题、步骤标记和小路径提示建立层级。底部操作卡片只保留当前可执行动作。业务错误提示临时覆盖底部卡片。

倒计时构建在 y=110 至 116 仅显示环境温度，例如 `TEMP 28C`。首帧采集前显示 `TEMP WAIT`，超时、时序或校验失败显示 `TEMP NO DATA`。湿度变化不触发重绘。

## 动画与增量刷新

- `UI_Init()` 清空 UI 缓存；不直接初始化 LCD，不进入任何业务页面。
- `UI_SetSnapshot(snapshot, now)` 复制最新快照，按页面变化启动擦入；同页则仅标记数值、档位、门、提示和进度条所在条带。
- `UI_RenderStep(now)` 由显示任务每约 10 ms 调用。每次最多发送两块条带，不等待整场动画结束。
- 普通换页由上向下擦入，青色细线表示扫描前沿；标题区使用左右箭头提示向前或返回。完整擦入约 200 ms（目标约 180 ms，实际受任务调度和传输影响）。
- 暂停、完成取消装饰动画，优先发送新状态，避免动作反馈被旧动画拖延。
- 动画期间收到更新页面即重启为最新目标，不排队播放过时页面。动画结束清除方向箭头。
- 页面稳定、快照内容不变时不发送像素；运行时按秒数和整数进度变化标记区域。

所有绘图原语根据条带范围裁剪，屏幕边缘不越界。时间采用无符号差值判断，支持系统毫秒计数回绕。

## 诊断与验证

`ui_rendered_bands` 统计实际提交的条带数，`ui_transition_count` 统计页面切换次数；仅由显示任务更新。

需验证各页预览、页切换无旧内容残留、快速按键时转向最新页、动画期间暂停立即生效，以及稳定页面不重复传输。构建与仿真结果由项目集成验证记录给出，实际屏幕颜色、方向和动画流畅度仍需开发板确认。
