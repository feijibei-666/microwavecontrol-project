# 第一阶段空载验收

常规固件接入门舵机、转盘、非阻塞有源蜂鸣器及 DHT11 环境温湿度显示，PA2 保持低电平。PB10 物理门反馈在末尾的低压 LED 联调构建中验收，测试期间保持 PTC 断开。

## 通电准备

1. 断电，断开 PTC 负载。继电器可以空载接入，但必须确认 IN 支持 3.3V 高电平触发、低电平可靠释放。PA2 不能直接驱动裸继电器线圈。
2. 门舵机 SIG 接 PB0，转盘 SIG 接 PA1，两个舵机 VCC 接外部稳定 5V、GND 与开发板共地。先卸下门舵机机械连杆，转盘保持无负载。按实际器件核对导线顺序。
3. 三脚有源蜂鸣器 IN 接 PB15，电源按模块额定值连接，输入须兼容 3.3V。裸两脚蜂鸣器需晶体管驱动。
4. USB 给开发板供电时，外部电源仅与开发板连接公共 GND，不并联外部 5V 至开发板 5V。外部电源容量须覆盖双舵机启动或堵转峰值。
5. 使用 SWD 下载最新 `build/Target 1/project.hex` 后复位。本地编译产物不提交到 Git；换电脑请重新构建。

PA2 从软件初始化开始保持低电平。复位到初始化前属于高阻窗口，需要模块自身或外部下拉保证继电器释放；不能依靠软件保证所有上电阶段。

## 按顺序测试

| 步骤 | 操作 | 预期行为 |
| --- | --- | --- |
| 1 | 上电后不按键 | LED 亮，欢迎页不自动跳转；门舵机到开门位置，转盘停止，蜂鸣器静音，继电器释放 |
| 2 | 短按 KEY1 | 门舵机到关门位置，LED 灭，进入主页；转盘仍停止 |
| 3 | 长按 KEY1，时间仍为 0 | 转盘不动，提示先设置时间，响一声 |
| 4 | 短按 KEY2 进入时间页，再短按一次 | 设置为 20 秒；可长按 KEY2 进入功率页，短按切档，再长按返回 |
| 5 | 长按 KEY1 | 进入运行页，转盘转动，响两声，倒计时持续；继电器仍释放 |
| 6 | 提示音或动画期间短按 KEY1 | 先发送转盘停止命令，再发送开门位置命令；LED 亮，倒计时暂停，响一声 |
| 7 | 短按 KEY1 关门 | 门舵机关闭、LED 灭，仍暂停且转盘停止，不自动恢复 |
| 8 | 长按 KEY1 恢复 | 转盘运行、响两声，剩余时间继续递减 |
| 9 | 等待归零 | 转盘停止，门舵机打开、LED 亮，进入完成页、响三声；时间归零，档位恢复 Medium |
| 10 | 短按 KEY1 | 关门、灭灯、返回主页，可再次设置并启动 |

全程 PA2 都应保持低电平，继电器不吸合。若继电器吸合，立即断电检查触发极性、接线与模块输入兼容性，不接 PTC 继续测试。

## 校准与诊断

- 门默认开 0°、关 90°，由 `bsp/servo.h` 的 `SERVO_ANGLE_OPEN`、`SERVO_ANGLE_CLOSE` 配置。先空载校准，再安装连杆；不要让舵机顶住机械限位。
- 转盘默认停止脉宽 1500 μs、运行脉宽 1000 μs，见 `bsp/turntable.h`。停止时仍缓慢转动，需逐步校准中位值；转速、方向取决于实际连续旋转舵机。
- 正常及故障停止命令最迟下一 20 ms PWM 帧生效，机械减速还需要时间；这不是机械制动或门安全联锁。
- 蜂鸣器每声 200 ms、间隔 150 ms。新提示会打断旧提示，因此快速连续操作可能只听到最新提示；这是为了及时反馈当前状态。
- 调试器检查 `rtos_fault_code`、`lcd_fault_code` 均为 0，`app_diagnostics.queue_overflows` 为 0。输入、控制、显示循环应持续增加；蜂鸣器空闲时阻塞等待，计数不持续增加属于正常情况。
- 应用任务最小剩余栈见 `app_diagnostics` 的 `*_stack_free`，单位为 32 位字。实机操作中确认有足够余量，不能用仿真代替 SPI/DMA、供电和机械验证。
- 出现 HardFault、断言、栈溢出等致命故障时，固件关闭继电器、停止转盘、静音并点亮 LED，保留故障码，需复位排查。看门狗和传感器保护留待后续阶段。

## 转盘与温湿度补测

- 倒计时 20 秒时在舵机信号端测 PA1。预期待机 1500 µs、运行 1000 µs、暂停和归零恢复 1500 µs，周期均约 20 ms。波形符合预期但不转时，核对舵机是否为连续旋转型号、供电是否稳定以及信号地是否相通。
- 接好 PA8 后等待首个采样周期。屏幕应从 `DHT11 WAIT` 切换为读数。断开信号线后，下一个采样周期应显示 `DHT11 NO DATA`，同时按键和倒计时仍应可用。

## 独立 PA2 空载诊断

保持 PTC 与触点侧电源断开，`COM`、`NO`、`NC` 留空。模块设为高电平触发，`IN` 接 PA2，按模块规格供电并与 STM32 共地。先确认模块兼容 3.3 V 高电平。

在独立测试构建中，给全部 C 文件增加预处理宏 `RELAY_NO_LOAD_TEST=1` 后全量重建。Keil 在 **Options for Target → C/C++ → Define** 添加；EIDE 可在 AC5 的 C 编译器选项中加 `-DRELAY_NO_LOAD_TEST=1`。默认工程配置未启用该宏。把诊断 HEX 与常规 HEX 分开放置，测试结束恢复常规构建和固件。

| 操作 | 预期 |
| --- | --- |
| 烧录诊断固件并上电 | LCD 显示 `RELAY TEST / NO LOAD`、`PA2 COMMAND OFF`，继电器释放 |
| 长按 KEY1 约 1 秒 | LCD 显示 `ON`，模块动作灯亮并发出吸合声 |
| 继续按住 KEY1 | 约 1 秒后自动变为 `OFF`，释放一次，不重复吸合 |
| 松开后重新长按 KEY1 | 再产生一次约 1 秒的吸合 |
| 吸合期间按复位 | 初始化时关闭 PA2；复位高阻窗口由模块输入默认电平或外部下拉覆盖 |

LCD 显示 PA2 命令。动作灯和吸合声用于初步确认机械动作，触点通断需单独验证。

## 低压 LED 倒计时联调

实机已确认单次诊断中，PA2 驱动继电器吸合和释放，接在 `COM–NO` 回路里的低压 LED 同步亮灭。继续沿用该 LED 和串联限流电阻，PTC 与市电保持断开。

用 `RELAY_LED_COUNTDOWN_TEST=1` 全量重建联调固件。各测试宏互斥，默认工程未启用任何测试宏。断电后接无源门开关，实际关门让 PB10 和 GND 导通，开门时断开。板上复位后先确认顶栏显示 `LED TEST / PA2 OFF`，拨动开关核对 `PB10 OPEN/CLOSED`。

| 操作 | 通过条件 |
| --- | --- |
| 欢迎页门开或关门后时间为零时长按 KEY1 | 不进入运行，LED 维持熄灭 |
| 短按 KEY1 发出关门命令，保持 PB10 开路，短按 KEY2 两次设为 20 秒，再长按 KEY1 | 可设置倒计时；实际门开时拒绝启动，LED 灭 |
| 闭合门开关，松开后重新长按 KEY1 | 显示 `LED TEST / PA2 ON`，外接 LED 持续亮 |
| 运行时直接断开 PB10 门开关或拔开开关线 | 首次采到开路后关闭 PA2，LED 灭，暂停并保留剩余时间 |
| 在暂停页重闭物理开关，再长按 KEY1 | 先显示 `PB10 CLOSED` 且 LED 仍灭，长按才恢复；若未发出 KEY1 开门命令，此处不用短按 KEY1 |
| 运行时短按 KEY1 模拟开门 | 短按被识别后进入暂停，PA2 变为 OFF，LED 灭，剩余时间保留 |
| 再短按 KEY1 关门，等待片刻，再长按 KEY1 | 关门后仍暂停且 LED 灭；长按后从剩余时间恢复，LED 亮 |
| 等待倒计时归零 | 进入完成页，LED 灭 |
| 另起一次倒计时，LED 点亮时复位 | 初始化后 PA2 为 OFF，LED 灭，等待重新操作 |

三个功率档在联调构建中均保持整个倒计时的 LED 亮灯命令。联调验证的是输出状态转换；触点回路仅接限流 LED。

## 5 V PTC 单次台架试热

独立构建使用 `PTC_BENCH_TEST=1`。长按 KEY1 触发一次约 10 秒的试热，KEY2 可提前停止。输出关闭后维持完成状态，复位后才可再次操作。

实机结果由操作者确认：PTC 正常发热，约 10 秒后继电器释放，LCD 显示 `TEST COMPLETE`。编译和仿真另覆盖提前停止、Tick 回绕和故障关断。正式倒计时加热和三档调功尚未接入。
