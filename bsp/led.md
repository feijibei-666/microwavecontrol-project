# led.c LED 驱动说明

## 引脚与电平

LED 使用 PC13，推挽输出、2 MHz 输出速度，低电平点亮、高电平熄灭。适用于带 PC13 低电平有效板载 LED 的 STM32F103C8 开发板。

`LED_ON()` 将 PC13 拉低，`LED_OFF()` 将 PC13 拉高。若使用外接 LED，需要匹配电路极性并串接合适的限流电阻，不能将负载直接当作逻辑输入连接。

## 初始化与交互

`LED_Init()` 开启 GPIOC 时钟，先将 PC13 输出锁存器置低，再配置推挽输出，默认点亮。主程序在调度器和屏幕初始化前调用，使欢迎页等待期间 LED 保持亮。

正常运行时由 `ControlTask` 独占业务状态，调用 `app.c` 中的软件开关门逻辑切换 LED；显示任务只读取快照，不控制 LED。RTOS 故障处理也会点亮 LED 并停止，便于发现异常。

| 软件状态或操作 | LED |
| --- | --- |
| 上电、欢迎／开门待机 | 亮 |
| 短按 KEY1 关门进入主页 | 灭 |
| 设置时短按 KEY1 开门返回欢迎页 | 亮 |
| 运行中短按 KEY1 开门暂停 | 亮 |
| 暂停时短按 KEY1 关门 | 灭，仍保持暂停 |
| 倒计时结束，软件门打开 | 亮 |
| 完成页短按 KEY1 开始下一轮 | 灭 |

LED 跟随软件门状态，不是实际门传感器的反馈。当前只恢复照明演示，不启用门锁、转盘和加热硬件。

## 验证要点

核对 GPIOC 时钟、PC13 推挽配置与输出电平；上电后 PC13 为低，第一次短按 KEY1 关门后为高。若实物不符合，应核对开发板 LED 是否确实连接 PC13，以及点亮极性是否为低电平有效。
